# 문서 작성 규칙

## 한 페이지의 기본 구조

```text
0. 이 페이지에서 배울 것
1. 전체 개념 지도
2. 핵심 개념과 관련 Q&A
3. 실제 시스템 적용
4. 아직 열린 질문
5. 1분 복습
6. 학습 업데이트 로그
```

## 코멘트 블록

질문은 관련 개념 바로 아래에 접힌 블록으로 남긴다.

```markdown
??? question "Q-20260802-01 · 질문 제목"
    **질문**

    실제 질문을 적는다.

    **답변**

    핵심 답변과 근거를 적는다.

    `상태: integrated`
```

| 블록 | 용도 |
|---|---|
| `question` | 새로 생긴 질문 |
| `note` | 이해를 돕는 추가 설명 |
| `warning` | 처음에 헷갈린 부분 |
| `failure` | 기존 설명의 정정 |
| `example` | CMF·로보틱스 등 실제 적용 |
| `success` | 질의응답 끝에 도달한 결론 |
| `tip` | 다른 개념·페이지와 연결 |

## 질문 상태

| 상태 | 의미 |
|---|---|
| `open` | 아직 답이 충분하지 않음 |
| `answered` | 답변했지만 본문에는 미반영 |
| `integrated` | 핵심 내용이 본문에도 반영됨 |

Q&A가 늘어나도 본문은 최신 상태를 유지해야 한다. 질문 때문에 이해가 바뀌면 먼저 본문을 고치고, Q&A는 학습 과정으로 남긴다.
