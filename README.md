# Concept Loop

질문하며 쌓아가는 AI 복습노트입니다.

- 공개 사이트: <https://dayo09.github.io/notes/>
- 원본은 `docs/` 아래의 Markdown 파일입니다.
- 공개 가능한 NLP·LLM·Agent·VLM·Robotics·생성형 AI 공부 자료만 다룹니다.

## 로컬 실행

```bash
python -m pip install -r requirements.txt
mkdocs serve
```

`main` 브랜치에 변경사항이 올라가면 GitHub Actions가 사이트를 빌드해 GitHub Pages에 배포합니다.
